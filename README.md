# SISTEMA DE SEGMENTACIÓN DE CLIENTES FINANCIEROS

---

# INTRODUCCIÓN

Actualmente, las entidades financieras generan grandes volúmenes de información sobre los hábitos de consumo, pagos y uso de tarjetas de crédito de sus clientes.

Sin embargo, muchas campañas comerciales continúan siendo enviadas de manera general, sin considerar las diferencias existentes entre los distintos perfiles de usuarios. Esta situación puede disminuir la efectividad de las estrategias de marketing y reducir la satisfacción de los clientes.

Frente a esta problemática, el presente proyecto propone el desarrollo de un sistema de segmentación basado en técnicas de Machine Learning no supervisado que permita identificar grupos de clientes con características similares para apoyar la toma de decisiones comerciales.

---

# ¿DE QUÉ TRATA EL PROYECTO?

El proyecto consiste en desarrollar un sistema de segmentación de clientes financieros utilizando el algoritmo K-Means Clustering.

A través del análisis de datos relacionados con hábitos de consumo, pagos, avances en efectivo y uso de tarjetas de crédito, se busca identificar perfiles de clientes con comportamientos similares.

La segmentación obtenida permite comprender mejor las características de cada grupo y diseñar estrategias comerciales más personalizadas.

---

# EXPLICACIÓN DE LA DATA

La información utilizada corresponde a registros financieros de clientes de tarjetas de crédito.

La data incluye variables relacionadas con:

* Compras realizadas
* Pagos efectuados
* Frecuencia de uso de la tarjeta
* Avances en efectivo
* Límite de crédito
* Saldo disponible
* Comportamiento financiero general

Durante el desarrollo del proyecto se realizaron procesos de:

* Limpieza de datos
* Preparación de variables
* Estandarización de datos
* Análisis exploratorio (EDA)
* Detección de valores atípicos
* Análisis de correlaciones

---

# PROBLEMÁTICA

Actualmente muchas entidades financieras aplican campañas promocionales generales para todos los clientes.

Sin embargo, cada usuario presenta comportamientos financieros diferentes, por lo que una misma estrategia no siempre resulta efectiva para todos.

La falta de segmentación dificulta la personalización de ofertas, limita el aprovechamiento de los datos disponibles y puede afectar la satisfacción del cliente.

---

# FINALIDAD DEL PROYECTO

La finalidad principal del proyecto es identificar grupos de clientes con características financieras similares mediante técnicas de análisis de datos y Machine Learning.

La segmentación obtenida permite apoyar la toma de decisiones comerciales, optimizar campañas de marketing y mejorar la personalización de productos y servicios financieros.

---
